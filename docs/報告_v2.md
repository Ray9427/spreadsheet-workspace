## 3. v2 の作り(要点)

- **置き場所**:新しく作る軽いファイル「軽量化ツール_診断」に入れます。本番・保管用・試験用は ID を登録して開くだけで、この版では書き込みません。ID はコードに書かず、メニューから登録します。
- **取り違え防止**:3つの ID が同じだったり、ツールのファイル自身だったりすると登録を断ります。確認の画面にはファイル名と ID の末尾を出し、名前に「試験」がない場合などは注意を出します。
- **重くしない読み方**:
  - 最初は名前・sheetId・表示・行列数だけを読みます。
  - 詳しい診断は、1回に最大 5 万セルずつ読みます。読み取りに失敗したら行数を半分にして読み直し、それでも読めない行は「調べられなかった行」として記録して先へ進みます。
- **続きから再開できる作り**:
  - 結果を書き込んでから、状態を保存します。途中で止まっても、最後に保存した所から重複なくやり直せます。
  - 続きの予約(トリガー)は1つだけにしています。止める指示が出たら、新しい処理は始めません。
  - 3回続けて進まなかったときは、自動の続きを止めます。
- **シートごとに調べる項目**:
  - 確保セル数、数式・定数・値・入力規則の最終位置
  - 条件付き書式、結合、保護、名前付き範囲、グラフ、ピボット、フィルタ、画像、図形(割り当てたスクリプト名も)
  - 列全体参照・A2:A 形式の参照
  - 重い式の分類:条件集計×列全体/配列計算×列全体/列全体を1行ずつ加工
  - 揮発性関数、INDIRECT・OFFSET、IMPORTRANGE(取得元と範囲)
  - エラー値、値と数式の指紋、参照関係
- **最終位置の2つの区別**:
  - 「内容と数式の最終位置」と、入力規則などの構造物を含めた「内容と構造物の最終位置(参考)」を分けて出します。
  - **外側のセルは「削除してよい」という意味ではない** と明記しています。
- **構造の比較**:「001」と行ごとに数式を比べ、各シートを「代表と同じ/一部だけ違う(違う行も表示)/別の作り/数式なし」に分けます。
- **比較基準**:比較する場所を Owner が選び、試験用コピーの値を記録します。そのとき本番と同じ値かも比べます。あとで「今の値」と比べて、違うセルを一覧にします。

## 5. 外部連携の改善方式の検討(優先順位2・実装は判断のあと)

前提:取り込み側のファイルと範囲が分かっていません。「001」の A1:AS35 は v1 の仮の範囲として扱い、必要な範囲が決まったとはしていません。

| 方式 | しくみ | 長所 | 短所・危険 |
|---|---|---|---|
| A. 同じファイルに値のシート(v1) | 本番の中に値だけのシートを作る | 取り込み側の変更が少ない | 取り込むときに重い本番を開くので、**タイムアウトが直らないおそれ**。本番のセルも増える |
| **B. 軽い中継ファイル(推奨)** | GAS が本番から必要な範囲を読み、確かめてから、値と表示形式を軽い「連携用」ファイルへ書く。取り込み側は中継ファイルを IMPORTRANGE する | 取り込み側の変更は、URL を中継ファイルに替えるだけ。前回の正常なデータを残し、更新日時と成否を表示できる。試験用の中継ファイルを別に作れる | ファイルが1つ増える。更新が遅れる(間隔しだい) |
| C. 取り込み側へ直接書く | GAS が取り込み側のシートへ値を書き込む | IMPORTRANGE そのものが不要 | 取り込み側の手入力欄を上書きする危険。書き込み権限が要る。取り込み側の数式の付け替えが要る |

**推奨は B** です。既存の業務への影響がいちばん小さく、失敗したときに前回のデータを守れるためです。C は、取り込み側に IMPORTRANGE を残せない事情がある場合だけにします。

B を作るときに守ること:
- 転記の前に確かめること:形、エラー値の数、「読み込み中」の数、空白が急に増えていないか。1つでも当てはまれば転記せず、前回のデータを残して「失敗」と記録する
- 表示形式を先に書き、値をあとに書く(文字列の「001」を守る)。1回の書き込みにまとめる
- 中継ファイルに、最終成功日時・今回の成否・読み取った時刻を表示する
- 更新は「手動」を先に完成させる。自動(時間主導トリガー)は、確認が済んでからオンにする
- onEdit は使わない。予約は1つだけにし、止める・再開する手段を用意する
- 計算が終わったことは保証できない。分かるのは「読み込み中」などの目に見えるしるしだけ、と画面と説明に書く
- 試験では、試験用コピーから試験用の中継ファイルへ書く。本番の中継ファイルの ID は試験の設定に入れない
