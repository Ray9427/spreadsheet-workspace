# 手順書 1:バックアップと「変更しない診断」

対象:歩合表(本番)の軽量化を始める前の準備です。
この手順書でやるのは **バックアップ** と **診断(読むだけ)** だけです。行の削除・数式の置き換え・自動転記は、まだ行いません。

- 所要時間の目安:準備 30〜40 分 + 診断の待ち時間(未測定。数十分の見込み。進み方は実行後に「進捗ログ」で分かります)
- 用意するもの:パソコンのブラウザ(Chrome がおすすめ)、本番の歩合表を編集できる Google アカウント

> 💡 用語
> - **本番**:いつも使っている「260900 歩合表」
> - **保管用バックアップ**:何かあったときに戻すためのコピー。**開くだけで、編集しない**
> - **試験用コピー**:診断や試験に使うコピー。本番の代わりに、ここで試す
> - **ツールのファイル**:新しく作る軽いスプレッドシート「軽量化ツール_診断」。コードと診断結果はここに入れる

> ✅ **2026-10-15 20:10〜20:12(日本時間)に Claude が代行したこと**(Google ドライブの機能でコピー・作成。本番は読んだだけで変更していません)
> - 手順 2:保管用バックアップ `【保管用・触らない】260900 歩合表_20261015_2010`
> - 手順 3:試験用コピー `【試験用】260900 歩合表_20261015_2010`
> - 手順 5 の 1〜2:空のスプレッドシート `軽量化ツール_診断`(本番と同じフォルダ)
>
> この2つのコピーは、本番の **19:56 時点** の内容です(シート 78 枚)。19:03 の `260900 歩合表_バックアップ_20261015`(シート 152 枚)とは構成が違うので、**19:03 のバックアップは消さずに残してください**。
> 代行していないこと:手順 1(版の名前付け)、手順 4(既存 GAS の退避)、手順 5 の 3 以降(コードを入れる)、手順 6 以降(承認と実行)。

## 0. 始める前に(2分)

1. **本番を編集しない時間を 30 分ほど確保してください**。共同で編集している人がいれば、その時間は編集しないよう伝えます。
   バックアップと試験用コピーを、同じ時点の内容にするためです。
2. 以前お渡しした **v1 のコード(「歩合表 軽量化ツール (Google Apps Script)」で始まるもの)を、本番の Apps Script に貼っていた場合**は、そのメニュー(本番のメニュー バーに出る「🛠 軽量化ツール」)を **使わないでください**。消すかどうかは、手順 4 で中身を退避してから相談します。

## 1. 本番の「今の版」に名前を付ける(3分)

変更履歴に、あとで戻るための目印を付けます。

1. 本番の「260900 歩合表」をブラウザで開きます。
2. 上のメニュー バーで **「ファイル」** をクリックします。
3. **「変更履歴」** にマウスを乗せ、右に出る **「現在の版に名前を付ける」** をクリックします。
4. 名前の欄に **`軽量化作業前_2026-10-15`** と入力し、**「保存」** を押します。
5. 確認:もう一度 **「ファイル」→「変更履歴」→「変更履歴を表示」** をクリックします。
   - 画面の右側に版の一覧が出て、いちばん上に **「軽量化作業前_2026-10-15」** があれば成功です。
   - 確認できたら、左上の **「←」(戻る矢印)** を押して、元の画面に戻ります。
   - ⚠️ この画面では「この版を復元」を押さないでください(押すのは、元に戻したいときだけです)。

## 2. 保管用バックアップを作る(5分)

> 今日の日本時間 19:03 ごろに「260900 歩合表_バックアップ_20261015」が作られています。ただ、本番はその後 19:23 ごろにも更新されています。
> そのため、**手順 0 で編集を止めたあとに、もう一度作ってください**。前のバックアップは消さずに、そのまま残しておいてください。

1. 本番を開いたまま、**「ファイル」→「コピーを作成」** をクリックします。
2. 出てきた画面で、次のように設定します。
   - **名前**:`【保管用・触らない】260900 歩合表_20261015`
   - **フォルダ**:そのまま(本番と同じ場所)で大丈夫です
   - **「同じユーザーと共有する」**:**チェックを外します**(ほかの人が誤って編集しないように)
   - 「コメントと提案をコピーする」:どちらでも構いません
3. **「コピーを作成」** を押します。新しいタブでコピーが開きます(大きいファイルなので、表示まで少し時間がかかることがあります)。
4. 確認:新しいタブの左上に `【保管用・触らない】…` と出て、下のシート タブ(000、001 …)が並んでいれば成功です。「001」を開いて、数字が表示されることも見てください。
5. このタブの **アドレス バー(上の URL 欄)の文字を全部コピー** して、メモ帳などに「保管用」として貼っておきます(手順 6 で使います)。
6. このタブは閉じます。**保管用は、これ以降は編集しません**。

## 3. 試験用コピーを作る(5分)

1. 本番のタブに戻り、もう一度 **「ファイル」→「コピーを作成」** をクリックします。
2. 設定:
   - **名前**:`【試験用】260900 歩合表_20261015`(名前に必ず「試験用」を入れてください。取り違えを防ぐためです)
   - **「同じユーザーと共有する」**:**チェックを外します**
3. **「コピーを作成」** を押し、開いたら、手順 2 と同じように中身が表示されるか確認します。
   - 一部のセルが `#REF!` になり「アクセスを許可」などと出ることがあります。ほかのファイルから値を取り込んでいるセルです。今は押さなくて大丈夫です。メモだけしておいてください。
4. アドレス バーの URL をコピーし、メモ帳に「試験用」として貼ります。
5. 本番のタブの URL も、メモ帳に「本番」として貼ります。

ここまでで、メモ帳に **本番・保管用・試験用** の3つの URL があれば OK です。

## 4. 本番にある GAS(Apps Script)を退避する(5〜10分)

本番にもとからあるプログラムを、念のため別の場所に写しておきます。**ここでは何も変更しません。**

1. 本番のタブで **「拡張機能」→「Apps Script」** をクリックします。新しいタブで Apps Script の画面が開きます。
2. 左の **「ファイル」** の下に並んでいるものを見ます。
   - **`コード.gs` だけがあって、中身が `function myFunction() {` と `}` だけ** → 既存の GAS はありません。手順 5 へ進んでください。
   - それ以外 → 次の 3〜5 を行います。
3. Google ドキュメントを新しく作ります(Google ドライブで「+ 新規」→「Google ドキュメント」)。名前は `既存GAS退避_260900_20261015` にします。
4. Apps Script の画面で、左のファイルを1つずつクリックします。右側のコードの中をクリックし、**Ctrl + A(すべて選択)→ Ctrl + C(コピー)** を押します。ドキュメントには、ファイル名を1行書いてから **Ctrl + V(貼り付け)** します。ファイルの数だけ繰り返します。
5. Apps Script の画面の左端にある **時計のアイコン(「トリガー」)** をクリックします。一覧に出ている行(関数名・イベントの種類)をドキュメントに書き写すか、画面を撮影して貼ります。
   - この一覧に出るのは、**自分が作ったトリガー** だけのことがあります。ほかに編集者がいる場合は、その人にも確認してください。
6. 確認:ドキュメントに、すべてのファイルの中身とトリガーの一覧が入っていれば成功です。
7. Apps Script のタブは、**何も変更せずに閉じます**。

> ⚠️ 退避した中に `openById` や `openByUrl` という文字があったら、ほかのファイルへ読み書きする処理です。試験用コピーにも同じコードが入っているので、**試験用コピーを編集する前に Claude に知らせてください**。
> この手順書の診断は試験用コピーを編集しないので、ここまでは問題ありません。

## 5. ツールのファイルを作り、コードを貼る(10分)

診断ツールは、本番ではなく **新しい軽いファイル** に入れます。本番の既存の GAS とぶつからないようにするためです。

1. ブラウザの新しいタブで **https://sheets.new** を開きます(空のスプレッドシートが作られます)。
2. 左上の **「無題のスプレッドシート」** をクリックし、`軽量化ツール_診断` と入力して **Enter** を押します。
3. **「拡張機能」→「Apps Script」** をクリックします。
4. 開いた画面の左上 **「無題のプロジェクト」** をクリックし、`軽量化ツール` と入力して **「名前を変更」** を押します。
5. 右側のコード欄(`function myFunction() {` と書いてあるところ)をクリックし、**Ctrl + A** を押してから **Delete** で消します。
   - ここは今作ったばかりの新しいファイルなので、消しても大丈夫です。
6. **Ctrl + V** で、Claude から受け取ったコード(`gas/軽量化ツール_v2.gs` の全体)を貼り付けます。
   - 先頭が `/**`、2行目が ` * 歩合表 軽量化ツール v2 —— 診断版` になっていれば正しく貼れています。
7. 上の **フロッピーディスクのアイコン(「プロジェクトを保存」)** を押すか、**Ctrl + S** で保存します。
   - 成功:エラー表示が出ず、左のファイル名の横の印が消えます。
   - 赤いエラーが出た場合:メッセージをそのまま Claude に送ってください。
8. スプレッドシート(「軽量化ツール_診断」)のタブに戻り、**F5 キー**(再読み込み)を押します。
9. 数秒待つと、メニュー バーの「ヘルプ」の右に **「🛠 軽量化ツール」** が出ます。出たら成功です。

## 6. 初回の承認と、対象ファイルの登録(5分)

### 6-1. 承認(最初の1回だけ)

1. **「🛠 軽量化ツール」→「はじめに(手順を表示)」** をクリックします。
2. 「承認が必要です」と出たら **「続行」** を押します。
3. 自分の Google アカウントを選びます。
4. 「**このアプリは Google で確認されていません**」と出ることがあります。自分で作ったスクリプトでは、ふつうに出る画面です。
   左下の **「詳細」** を押し、**「軽量化ツール(安全ではないページ)に移動」** を押します。
5. 許可する内容の一覧が出ます。チェックボックスがあれば **「すべて選択」** にしてから、**「続行」**(または「許可」)を押します。
   - 一覧には「スプレッドシートの表示、編集、作成、削除」と出ます。これは、ID を指定して別のファイルを開くために Google が求める権限です。細かく分けられないので、この表示になります。
   - **この版のコードには、本番・保管用・試験用に書き込む命令はありません**。ローカルの試験では、書き込もうとすると止まる模擬ファイルで動かして確かめました。
6. 承認のあと、もう一度 **「🛠 軽量化ツール」→「はじめに」** を押します。
   - 成功:「はじめに」という名前のシートができ、手順が書かれた画面が出ます。

### 6-2. 対象ファイルの登録

1. **「🛠 軽量化ツール」→「1. 対象ファイルを登録する」** をクリックします。
2. 入力欄が3回出ます。メモ帳の URL を、言われた順番に貼って **OK** を押します。
   1回目 **本番** → 2回目 **保管用** → 3回目 **試験用**
3. 確認の画面に3つのファイル名が出ます。**名前と順番が合っているか** を見て、**「はい」** を押します。
   - 同じ URL を2回貼った場合や、ツールのファイル自身を貼った場合は「登録できません」と出ます。その場合は 1 からやり直します。
4. 成功:「登録しました」と出ます。

## 9. 詳しい診断(待ち時間あり)

v2.1 では、**最初は自動の続きがオフ** です。まず手動で1回分だけ動かして、結果を確かめます。

1. **「4. 詳しい診断を始める/続ける(変更しない)」** をクリックします。
2. 確認の画面で、対象が「【試験用】…」で、「自動の続き: オフ」と書いてあるのを確かめて **「はい」** を押します。
3. 1回は最大で約 4.5 分かかります。上に「スクリプトを実行しています」と出ている間は待ちます。
4. 「時間で区切った … 続きは「4. 詳しい診断を始める/続ける」をもう一度押してください」と出たら、1回分は終わりです。**ここで一度 Claude に知らせてください**(シート「進捗ログ」を読んで、問題がないか確かめます)。
5. 確かめたあとの続け方は2つです。
   - **手動で続ける**:「4.」を押すたびに約 4.5 分ずつ進みます。
   - **自動で続ける**:**「自動の続きをオンにする(小さな試験と手動1回の確認後)」** を押して「はい」→「4.」を押します。以後は区切りのたびに1分後に自動で続きます。画面やパソコンを閉じても、Google 側で続きが動きます。
6. 進み具合を見るときは **「5. 診断の進み具合を見る」** を押します(「進み具合: ○ / △ シート」「自動の続き: オン/オフ」)。
7. 完了の確認:「5.」で「状態: 完了」と出るか、シート「進捗ログ」の最後の行の「結果」が「完了」になれば終わりです。シート **「診断サマリー」** ができています。

**診断中の注意**
- **試験用コピーは編集しないでください**(結果がずれます)。本番は通常どおり使って構いません(この診断は試験用コピーだけを読みます)。
- 止めたいとき:**「6. 診断を止める」**。今読んでいる区切りが終わったところで止まります(1回の読み取りの途中では止まりません)。再開は「4.」です。自動の続きだけをやめたいときは **「自動の続きをオフにする」** を押します。
- 「進捗ログ」に **「3回続けて進まなかった」** や **「エラー」** と出たら、自動の続きは止まります。メッセージを Claude に送ってください。
- 「1日に使用できるコンピュータ時間」などのエラーが出たときは、Google の1日の上限に達しています(無料のアカウントでは、自動実行の合計が1日 90 分程度)。翌日に「4.」を押すと続きから進みます。

## 10. 比較基準を記録する(5〜10分)

変更前の「正しい値」を記録しておき、あとで変更したときに同じ値が出るかを比べるためのものです。

1. **「8. 比較する場所の候補を作る」** をクリックします。シート「比較対象」に候補が入ります(代表の「001」と、名前に支給・給与・売上・各店・集計・合計を含むシート)。
2. シート「比較対象」を見て、次のように直します。
   - **特に間違ってはいけない場所**(歩合・給与・店舗別合計・支給額など)が入っているかを確かめます。
   - いらない行は、A 列のチェックを外します。
   - 足りない場所は、下の行に追加します。B 列にシート名を、C 列に範囲を書きます(例 `A1:O354`。空欄にすると、使われている範囲全体になります)。
3. **「9. 比較基準(今の値)を記録する(変更しない)」** をクリックし、確認の画面で **「はい」** を押します。
4. 成功:シート「比較基準一覧」に1行ずつ記録されます。
   - **「本番との違い(セル)」が 0** なら、試験用コピーと本番の値が同じです。
   - 0 でないとき:コピーのあとに本番を編集したか、IMPORTRANGE の許可待ちなどが考えられます。「本番との違い(例)」の列を Claude に送ってください。
5. (確認用)**「10. 今の値を比較基準と比べる」** を押すと、シート「比較結果」に「同じ」と出ます。`TODAY()` を使うセルは、日付が変わると違いとして出ます。
